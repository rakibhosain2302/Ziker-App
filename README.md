🌙 Ziker-App

Ziker-App is a modern Islamic Tasbih & Zikr Counter application built with React.
It helps users perform daily zikr, track progress, rotate duas, and maintain consistency with a clean and calming UI.

✨ Features

🕌 Islamic Tasbih & Zikr Counter

🔢 Multiple counting modes (33, 99, Infinity)

📿 Large animated circular progress indicator

🔄 Next / Previous dua slider

🌄 Dynamic background changer

💾 Daily zikr saved using localStorage (auto reset each day)

📅 One-day zikr tracking system

🎨 Modern UI with smooth animations

🧩 Component-based clean architecture

🛠️ Tech Stack

Frontend: React (Vite)

Styling: Bootstrap + Custom CSS

Icons: React Icons

State Management: React Hooks

Storage: Browser LocalStorage
